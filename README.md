# HerSpace 

HerSpace is a web application designed to help students manage their menstrual cycles alongside their academic schedules.

## Features
- User registration and login.
- Menstrual cycle tracking.
- Academic calendar for managing events.
- Smart Overlap to identify possible conflicts between estimated cycle dates and academic activities.
- Firebase authentication and database integration.

## Technologies Used
- React.js
- JavaScript
- CSS
- Firebase (Authentication and Firestore)
- Vite

## Project Status
Approximately 70–80% complete. Her Support and Her Circle are the remaining pages under development.

## Getting Started

1. Clone the repository.
2. Run `npm install`.
3. Configure your Firebase environment variables in a `.env` file.
4. Run `npm run dev`.
